# Template T3 — Nhân vật

> Trạng thái: CHỐT

Mọi nhân vật nằm trong `content/characters.md`, mỗi nhân vật một khối. P1 chuyển thành `data/characters.json`. File này phải chuyển **trước** các file kỳ.

## Khối để chép

```markdown
## NHÂN VẬT ma-nhan-vat

- Mã: ma-nhan-vat
- Tên hiển thị: 
- Loại: hư cấu | lịch sử | hệ thống
- Mô tả: 
- Tâm trạng sprite: binh-thuong, vui, lo-lang
```

`Loại: lịch sử` → nhân vật chỉ được nói câu có nguồn `kind: quote` (`docs/03-story-spec.md` mục 4). `Loại: hệ thống` → để `Tâm trạng sprite: không`.
